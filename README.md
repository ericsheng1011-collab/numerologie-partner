# NUMEROLOGIE — Partner site preview

English + Japanese (`ja/`) B2B brand / wholesale site for selective sales partners and reps worldwide (including Europe, Japan, the Middle East, and other markets). **Not** a Shopify or D2C storefront. Brand origin: the South of France (designed in France, manufactured in China).

We work primarily with commission-based sales representatives. What matters is selling to brand-aligned customers.

## Open locally

```bash
cd /workspace/partner-site
python3 -m http.server 8765
```

Then open `http://127.0.0.1:8765/` (or open `index.html` directly in a browser).
